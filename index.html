SoftEther VPN deb repository

SoftEther VPN packages built from the official upstream release for Debian 13 (trixie) and Ubuntu 26.04 (resolute), with one local patch: the enterprise feature restrictions of the open source build are disabled.

Add the repository (DEB822)

/etc/apt/sources.list.d/softether.sources:

Types: deb
URIs: https://kouhj.github.io/softether-deb/
Suites: bullseye bookworm trixie forky duke jammy noble resolute 
Components: main
Architectures: amd64
Signed-By: /etc/apt/keyrings/softether-deb.asc

The signing key:

sudo install -d /etc/apt/keyrings
curl -fsSL https://kouhj.github.io/softether-deb/softether-deb.asc \
  | sudo tee /etc/apt/keyrings/softether-deb.asc >/dev/null

Then sudo apt update && sudo apt install softether-vpnserver.
